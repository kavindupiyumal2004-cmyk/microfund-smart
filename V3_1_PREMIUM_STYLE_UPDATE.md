# MicroFund V3.1 — Premium UI Style Refresh

This update changes the existing five-role system visually to match the approved MicroFund dashboard mockups while keeping the existing backend workflow and API logic intact.

## Changed
- Dark navy professional sidebar with gradient active navigation.
- New MicroFund brand mark/tagline presentation.
- Modern top bar with search field, notification bell and role/user profile.
- Role-aware dashboard greeting and date card.
- Premium KPI cards with six accent tones.
- Cleaner recent-activity panel.
- Shared premium styling for forms, panels, filters, tables, buttons, cards and status badges.
- Responsive desktop/tablet/mobile adjustments.

## Main files changed
- `frontend/src/components/DashboardLayout.jsx`
- `frontend/src/pages/dashboard/DashboardHome.jsx`
- `frontend/src/styles/global.css`

No loan, repayment, collection, role-permission, approval or API business logic was changed by this visual update.
